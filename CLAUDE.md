# Контекст проекта

## О чём проект
Делаем видео для недвижимости в **Словакии**.

## Цель и планка качества
- Местный рынок недвижимого видео слабый и «грустный» — шаблонные, скучные ролики.
- Ориентир — не словацкий рынок, а **Запад: США, Канада и др.**, топовые Instagram-аккаунты по недвижимости.
- Всё, что делаем, должно выдерживать сравнение с их уровнем: кинематографичные движения камеры (дрон-пролёты, проходы через двери и комнаты), ритм монтажа, цвет, звук, подача.

## Инструменты
- Видео из фото (image-to-video) через Higgsfield MCP: пролёты как с дрона, движение камеры, оживление сцены.
- Перед генерацией проверять баланс кредитов; сложные сцены (двери, проходы сквозь объекты) могут требовать 1–2 перегенерации.

## Рабочие договорённости
- Общаться с пользователем по-русски.
- Контент — для словацкого рынка недвижимости (учитывать локальный контекст: Братислава, Кошице, регионы, словацкий язык в тексте/субтитрах, если нужно).

## Студия агентов
- В папке `agent-studio/` лежит личная программа для Windows (Electron): схема ИИ-агентов, блоки соединены линиями, агенты по-настоящему вызывают Claude API.
- `.exe` собирается сам на GitHub Actions (`.github/workflows/build-windows.yml`) после каждого изменения в `agent-studio/`.
- Банк идей и статусы агентов: `IDEAS.md`. Обновлять статусы, когда что-то сделано.
- Направление: начинаем с видео для недвижимости, но бизнес не ограничиваем видео.

## Заметки для Obsidian
- Итоги облачных сессий ведём в `vault/` (формат Obsidian, `[[ссылки]]`); пользователь подтягивает папку в свой vault через git (см. `vault/README.md`).
- В конце сессии, где что-то решили или сделали: добавить `vault/Сессии/ГГГГ-ММ-ДД <тема>.md` (что сделали, решения, что не закончено, ссылка на сессию), обновить заметку проекта в `vault/Проекты/`, новые уроки — в `vault/Знания/`, ссылку — в `vault/Главная.md`.
- Репозиторий публичный: личное и секреты в заметки не писать.

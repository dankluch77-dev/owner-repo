**Подпись к посту:** `caption.txt` (1739 символов из 2200, все промпты внутри).

Логика подписи: первые две строки видны до «ещё» — в них хук и вопрос с вариантами 1–4 (легко ответить → комментарии). Дальше призыв сохранить пост (сохранения — сильный сигнал для алгоритма) и сами промпты.

Запасные варианты подписи:
- **Ключевое слово:** `Comment "PROMPT" and I'll DM you all 4.` — больше комментариев и переписок, но на каждый комментарий надо отвечать в директ (вручную или через автоответчик, например ManyChat).
- **Коротко:** `Real or AI? 👀 Trick question — none of it was filmed. Prompts in the first comment ↓` — промпты закрепить первым комментарием.

## Как публиковать
1. Загрузить mp4 в Instagram как Reel.
2. Добавить трендовый звук из библиотеки Instagram (в файле только тишина, чтобы звук не заглушили за авторские права).
3. Обложка — первый кадр (на нём хук).
4. Вставить подпись из `caption.txt`.

## Сборка
- `overlays.html` + `render-overlays.js` — хук, счётчик «SHOT 0X / 04», заставка 2 с: только логотип и @vavermo, без лишнего текста (Playwright → PNG в `build/`).
- `build.sh` — монтаж ffmpeg: обрезка, лёгкий контраст/насыщенность, наложение графики, заставка, тишина.
- Исходные клипы кладутся в `build/clips/1..4.mp4` (папка `build/` не коммитится).

Сеть этой сессии не пускает на CDN Higgsfield, поэтому сборка запускалась в песочнице Higgsfield (`sandbox_exec`) теми же скриптами.

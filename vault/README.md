# Заметки Claude для Obsidian

Claude ведёт здесь итоги облачных сессий в формате Obsidian: проекты, знания, сессии, `[[связи]]`. Начинать с [[Главная]].

- `Проекты/`: по заметке на каждое направление, с решениями и открытыми задачами.
- `Знания/`: то, что пригодится снова (правила генерации, референсы, расходы).
- `Сессии/`: по заметке на сессию, имя файла начинается с даты.

## Как подтянуть в свой vault на Windows (один раз)

1. Установить Git, если его нет: https://git-scm.com/download/win (все настройки по умолчанию).
2. Открыть «Командную строку» и выполнить, заменив путь на свой vault:

   ```
   cd "C:\путь\к\vault"
   git clone --filter=blob:none --sparse -b claude/peaceful-cannon-asec2s https://github.com/dankluch77-dev/owner-repo.git Claude
   cd Claude
   git sparse-checkout set vault
   ```

   В vault появится папка `Claude\vault\` только с заметками, без кода.

3. Автообновление раз в 30 минут:

   ```
   schtasks /create /tn "Claude vault sync" /sc minute /mo 30 /tr "git -C \"C:\путь\к\vault\Claude\" pull --ff-only"
   ```

   Обновить вручную: `git -C "C:\путь\к\vault\Claude" pull`.

## Важно
- Синхронизация идёт в одну сторону: Claude пишет, Obsidian читает. Свои мысли записывайте в отдельные заметки, а эти файлы не правьте, иначе обновление остановится на конфликте.
- Репозиторий публичный, и эти заметки видны всем на GitHub. Личное сюда не писать.

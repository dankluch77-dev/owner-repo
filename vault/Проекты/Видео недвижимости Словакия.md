# Видео недвижимости Словакия

## Суть
Делаем видео для недвижимости в Словакии. Местный рынок слабый и «грустный», поэтому меряемся не с ним, а с топовыми Instagram-аккаунтами США и Канады: кинематографичные пролёты, проходы через двери, ритм, цвет, звук, подача.

## Как делаем
- Видео из фото через Higgsfield (image-to-video): Kling 3.0 для проходов через двери, Cinema Studio Video для интерьера, Veo 3.1 для фасада и вида.
- Сценарий, хук и ритм берём на себя: именно они отличают топ-аккаунты, а не только картинка. См. [[Референсы — западные аккаунты]].
- Цвет и ритм монтажа можно снимать с референсов измерением. См. [[Правила генерации видео]] и [[everything-claude-code]].
- Для премиум-объектов есть формат «образ жизни». См. [[Монтаж в стиле lifestyle]].
- Цепочка агентов «Видео объекта» в [[Студия агентов]] готовит карточку объекта, раскадровку, промпты и словацкий текст.

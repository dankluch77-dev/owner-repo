# Студия агентов

Личная программа для Windows (Electron + Anthropic SDK). На поле нарисованы ИИ-агенты и связи между ними. Цепочку можно прогнать в симуляции (бесплатно) или по-настоящему через Claude API.

- Код: папка `agent-studio/` в репозитории, основная ветка `claude/peaceful-cannon-asec2s`.
- `.exe` собирается сам на GitHub Actions после каждого изменения: Actions → «Сборка Windows exe» → Artifacts → `AgentStudio-windows`.
- Ключ API вставляется кнопкой «Ключ API» и хранится зашифрованным в `%APPDATA%\agent-studio\api-key.bin`.
- Банк идей и статусы агентов: `IDEAS.md` в репозитории.

## Что умеет (v0.4.0)
- Настоящий вызов Claude, веб-поиск и чтение страниц у агентов (поиск около $0,01 за запрос, до 10 за ход).
- «Последний запуск»: что ушло в модель, ответ, токены, время, стоимость, источники.
- Шаблоны цепочек:
  - **Видео объекта:** Приёмщик → Режиссёр-сценарист → Автор промптов Higgsfield → Копирайтер SK;
  - **Поиск клиентов:** Охотник за клиентами (nehnutelnosti.sk, reality.sk) → Автор писем на словацком;
  - **Разведка трендов**, **Смета заказа**, **Отчёт клиенту**.

## Решения
- Режим «по подписке через Claude Code» не добавляли: программа работает через API, оплата идёт с баланса console.anthropic.com.
- Чтобы было дешевле, агентам можно ставить Sonnet 5.5 или Haiku 4.5 с низким усилием.
- Направление: начинаем с видео для недвижимости, но бизнес видео не ограничиваем.

# 2026-10-04 Студия агентов

**Проект:** [[Студия агентов]]

## Что сделали
- Программа для Windows: блоки агентов, связи, шаги, промпты, модели. Запуск в симуляции или по-настоящему.
- Сборка `.exe` на GitHub Actions после каждого изменения.
- Этап 2: агенты по-настоящему вызывают Claude API, видно токены, время и стоимость.
- Веб-поиск и чтение страниц для агентов.
- Банк идей `IDEAS.md`.
- Шаблоны: Видео объекта, Поиск клиентов, Разведка трендов, Смета заказа, Отчёт клиенту.
- Иконка, версия 0.4.0.

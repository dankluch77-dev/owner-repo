# Студия агентов

Личная программа для Windows: на поле видно, как устроены ИИ-агенты и как они связаны между собой.

- Блоки соединяются линиями: от правого кружка одного блока к левому кружку другого.
- Нажми на агента, и справа откроется всё о нём: что получает, какие шаги выполняет, промпты, модель и что отдаёт дальше.
- Кнопка **Запуск** прогоняет данные по цепочке: агенты подсвечиваются по очереди, шаги идут по порядку, по линиям едут данные.

Сейчас это **этап 1, визуал**: запуск показывается как симуляция, настоящий ИИ не вызывается.

## Как запустить на Windows

1. Один раз установи **Node.js** (версия LTS): https://nodejs.org
2. Открой папку `agent-studio` и дважды щёлкни `start-windows.bat`.
   При первом запуске он скачает Electron (около минуты), потом откроется окно программы.
   Дальше программа будет открываться сразу.

Запуск из терминала: `npm install`, потом `npm start`.

## Управление

| Действие | Как |
|---|---|
| Новый агент | кнопка «Агент» или двойной клик по полю |
| Соединить блоки | тянуть от правого кружка к другому блоку |
| Двигать блок | тянуть за блок |
| Двигать поле | тянуть за пустое место |
| Масштаб | колесо мыши; клик по проценту показывает всю схему |
| Удалить | выделить блок или линию и нажать Delete (можно вернуть из уведомления) |

## Где хранится схема

Схема сохраняется сама после каждого изменения в файл `%APPDATA%\agent-studio\schema.json`.
Кнопки «Экспорт» и «Импорт» сохраняют схему в отдельный файл и открывают её обратно (для копий и обмена).

## Устройство

- `main.js`: окно программы, чтение и запись файлов.
- `preload.js`: безопасный мост между окном и файлами.
- `src/index.html`, `src/styles.css`, `src/app.js`: интерфейс, поле, панель агента, симуляция.

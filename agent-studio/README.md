# Студия агентов

Личная программа для Windows: на поле видно, как устроены ИИ-агенты и как они связаны между собой.

- Блоки соединяются линиями: от правого кружка одного блока к левому кружку другого.
- Нажми на агента, и справа откроется всё о нём: что получает, какие шаги выполняет, промпты, модель и что отдаёт дальше.
- Кнопка **Запуск** прогоняет данные по цепочке: агенты подсвечиваются по очереди, шаги идут по порядку, по линиям едут данные.

У запуска два режима (переключатель рядом с кнопкой «Запуск»):

- **Симуляция**: бесплатная анимация, ИИ не вызывается.
- **Claude API**: каждый агент по-настоящему отправляет запрос модели Claude. Вход подставляется в шаблон запроса вместо `{{вход}}`, ответ приходит по мере написания и уходит по линии дальше. В панели агента, в разделе «Последний запуск», видно, что ушло в модель, как она рассуждала (кратко), её ответ, токены, время и примерную стоимость.

## Шаблоны

Кнопка **«Шаблоны»** добавляет на поле готовую цепочку агентов (под тем, что уже есть):

- **Поиск клиентов**: Охотник за клиентами ищет в интернете риелторов без сильного видео и собирает публичные контакты агентств, Автор писем пишет каждому первое письмо на словацком с переводом.
- **Разведка трендов**: что сейчас работает у топовых аккаунтов недвижимости в США и Канаде, со ссылками на источники.
- **Смета заказа**: кредиты Higgsfield, часы работы и три варианта цены. Цифры в примере условные, замени своими.
- **Отчёт клиенту**: письмо на словацком со ссылкой на ролик и результатами.

Промпты, шаги и модели в шаблонах можно менять как у любого агента.

## Инструменты агентов

В панели агента, в разделе «Инструменты»:

- **Веб-поиск**: агент сам ищет в интернете (около $0,01 за запрос, не больше 10 запросов за ход).
- **Чтение страниц**: агент открывает найденные ссылки и читает страницу целиком.

В «Последнем запуске» видно, что агент искал и какие страницы открывал, и список источников.

## Ключ API

Для режима «Claude API» нужен ключ из консоли Anthropic: https://console.anthropic.com/settings/keys.
Вставь его кнопкой **«Ключ API»** в верхней панели: программа проверит ключ и сохранит его в зашифрованном виде средствами Windows (`%APPDATA%\agent-studio\api-key.bin`).
Запросы оплачиваются с баланса аккаунта Anthropic. Цены моделей видны в панели агента.

## Как запустить на Windows

### Готовый .exe (проще всего)

1. На GitHub открой вкладку **Actions** → «Сборка Windows exe» → самый верхний запуск с зелёной галочкой.
2. Внизу страницы, в разделе **Artifacts**, скачай `AgentStudio-windows` и распакуй архив.
3. Дважды щёлкни `AgentStudio-<версия>.exe`. Если Windows покажет синее окно «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае»: файл не подписан платным сертификатом, это нормально для личной программы.

Новый .exe собирается сам после каждого изменения программы.

### Через Node.js (для разработки)

1. Один раз установи **Node.js** (версия LTS): https://nodejs.org
2. Открой папку `agent-studio` и дважды щёлкни `start-windows.bat`.
   При первом запуске он скачает Electron (около минуты), потом откроется окно программы.
   Дальше программа будет открываться сразу.

Запуск из терминала: `npm install`, потом `npm start`.

## Управление

| Действие | Как |
|---|---|
| Новый агент | кнопка «Агент» или двойной клик по полю |
| Соединить блоки | тянуть от правого кружка к другому блоку |
| Двигать блок | тянуть за блок |
| Двигать поле | тянуть за пустое место |
| Масштаб | колесо мыши; клик по проценту показывает всю схему |
| Удалить | выделить блок или линию и нажать Delete (можно вернуть из уведомления) |

## Где хранится схема

Схема сохраняется сама после каждого изменения в файл `%APPDATA%\agent-studio\schema.json`.
Кнопки «Экспорт» и «Импорт» сохраняют схему в отдельный файл и открывают её обратно (для копий и обмена).

## Устройство

- `main.js`: окно программы, чтение и запись файлов.
- `ai.js`: ключ API и вызовы Claude (официальная библиотека `@anthropic-ai/sdk`, потоковые ответы, веб-поиск и чтение страниц).
- `src/templates.js`: готовые цепочки агентов для меню «Шаблоны».
- `preload.js`: безопасный мост между окном и файлами.
- `src/index.html`, `src/styles.css`, `src/app.js`: интерфейс, поле, панель агента, симуляция.

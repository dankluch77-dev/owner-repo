Ключ API Anthropic

Ключ нужен, чтобы агенты отправляли запросы модели Claude. Создать его можно в консоли Anthropic: console.anthropic.com → API keys.

Каждый запуск в режиме «Claude API» оплачивается с баланса этого аккаунта. Цена видна у каждой модели и в разделе «Последний запуск».

Ключ хранится только на этом компьютере в зашифрованном виде (средствами Windows) и отправляется только в Anthropic.
